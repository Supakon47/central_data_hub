# Import profiles

ไฟล์ JSON หนึ่งไฟล์ต่อ workbook หนึ่งไฟล์ บอกตัวนำเข้า (`python -m app.import_profile`) ว่าจะอ่านไฟล์นั้นอย่างไร ไฟล์ Excel ต้นฉบับถูกอ่านอย่างเดียวเสมอ

```json
{
  "source_name": "ห้องโลหะ 2",
  "file": "รายการโบราณวัตถุห้องโลหะ2.xlsx",
  "role": "location",
  "header_row": 1,
  "description": "รายการวัตถุและชั้นวาง ห้องคลังโลหะ 2",
  "owner_name": "ยังไม่ระบุ",
  "sheets": {
    "นอกชั้น": {"location": "นอกชั้น"},
    "สรุปยอด": {"skip": "ชีตสรุปยอดจำนวนต่อชั้น ไม่ใช่รายการวัตถุ"}
  },
  "notes": ["ข้อสังเกตเกี่ยวกับไฟล์นี้"]
}
```

| ค่า | ความหมาย |
|---|---|
| `source_name` | ชื่อแหล่งข้อมูลใน Data Hub (ห้ามซ้ำกับ profile อื่น) |
| `file` | ชื่อไฟล์ในโฟลเดอร์ RawData (`RAWDATA_DIR`, ใน container คือ `/rawdata`) |
| `role` | บทบาทตั้งต้นของทุกชีต: `register` = ทะเบียน/คำบรรยายวัตถุ, `location` = บัญชีห้องคลังที่บอกตำแหน่ง |
| `header_row` | แถวที่เป็นหัวตาราง (ตั้งต้น 1) |
| `sheets.<ชื่อชีต>.skip` | ข้ามชีตนี้ พร้อมเหตุผล (เช่น ชีตสรุปยอด) |
| `sheets.<ชื่อชีต>.role` / `header_row` | ใช้แทนค่าตั้งต้นสำหรับชีตนี้ |
| `sheets.<ชื่อชีต>.location` | ตำแหน่งของแถวที่ไม่มีคอลัมน์ตำแหน่ง เมื่อชีตเองคือสถานที่ (เช่น "นอกชั้น") |

ชีตที่ไม่ได้ระบุใน `sheets` ใช้ค่าตั้งต้น ถ้า profile ระบุชื่อชีตที่ไม่มีในไฟล์ ระบบจะปฏิเสธทั้ง profile

กติกาที่ใช้กับทุก profile:
- ข้ามแถวที่ไม่มีทั้งเลขทะเบียนและชื่อ (เช่น เลขลำดับที่เติมไว้ยาวเกินข้อมูล) และแถวยอดรวม (เลขทะเบียนขึ้นต้นด้วย "จำนวน" หรือ "รวม")
- หยุดอ่านชีตเมื่อเจอแถวว่างติดกัน 1,000 แถว
- นำเข้าซ้ำได้: แถวที่ไม่เปลี่ยนจะไม่ถูกแก้

```powershell
# ตรวจก่อน (ไม่บันทึกอะไร)
docker compose --profile trial run --rm web-trial python -m app.import_profile backend/import_profiles --dry-run
# นำเข้าจริงในฐานทดลอง
docker compose --profile trial run --rm web-trial python -m app.import_profile backend/import_profiles
```
