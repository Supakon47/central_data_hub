# คู่มือใช้คอมพิวเตอร์กลางสำหรับ Central Data Hub

เอกสารนี้ใช้สำหรับผู้ดูแลที่ติดตั้งระบบหนึ่งครั้ง เพื่อให้เจ้าหน้าที่ทั่วไปใช้งานผ่านเว็บเบราว์เซอร์เท่านั้น

## หน้าที่ของเครื่องกลาง

- เก็บ container ของ Data Hub และ PostgreSQL
- เก็บไฟล์ `.env` และ service-account JSON ในเครื่องเท่านั้น
- ทำงานเมื่อ Windows และ Docker Desktop เปิดอยู่
- ให้เจ้าหน้าที่ในเครือข่ายภายในเข้าเว็บไซต์ผ่าน IP หรือชื่อเครื่อง

เจ้าหน้าที่ทั่วไปไม่ต้องเปิด Docker, Terminal หรือเห็น service-account key

## ตั้งค่าหนึ่งครั้ง

1. เลือกคอมพิวเตอร์ที่ไม่ใช่เครื่องใช้งานส่วนตัวหลัก และตั้งค่าไม่ให้ Sleep ระหว่างเวลางาน
2. ติดตั้ง Docker Desktop แล้วเปิดตัวเลือกให้ Docker Desktop เริ่มเมื่อผู้ดูแล Windows ลงชื่อเข้าใช้
3. วางโฟลเดอร์ `Central-data-hub` ไว้ในตำแหน่งถาวร อย่าย้ายหลังตั้งการเปิดอัตโนมัติแล้ว
4. สร้าง `.env` จาก `.env.example` และตั้งค่า administrator / service account ตามคู่มือหลัก
5. สร้าง `docker-compose.google-sheets.yml` ในเครื่อง หากต้องใช้ Google Sheets และทดสอบเปิดระบบหนึ่งครั้ง
6. ให้ผู้ดูแลรัน `scripts\Install-CentralDataHubAutoStart.ps1` หนึ่งครั้งตามคำสั่งด้านล่าง
7. ตั้ง IP คงที่หรือ DHCP reservation ที่ router แล้วบันทึก URL ที่เจ้าหน้าที่จะใช้

## ติดตั้งการเปิดระบบอัตโนมัติ

เปิด PowerShell ในโฟลเดอร์โครงการ แล้วรันหนึ่งครั้ง:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Install-CentralDataHubAutoStart.ps1
```

งานนี้จะเริ่ม Data Hub หลังผู้ดูแล Windows ลงชื่อเข้าใช้ โดยรอ Docker Desktop พร้อมก่อนสูงสุด 5 นาที และบันทึกผลไว้ที่ `data\logs\central-data-hub-startup.log`

Docker Compose มี `restart: unless-stopped` แล้ว ดังนั้นหาก Docker engine รีสตาร์ต container ฐานข้อมูลและเว็บจะกลับมาทำงานเอง

## แจก URL ให้เจ้าหน้าที่

บนเครื่องกลาง ให้เปิด Command Prompt แล้วใช้ `ipconfig` เพื่อดู IPv4 ของเครือข่ายภายใน เช่น `192.168.1.50` จากนั้นให้เจ้าหน้าที่ใช้:

```text
http://192.168.1.50:8000
```

แนะนำให้ฝ่าย IT ทำ DHCP reservation หรือชื่อเครื่องภายใน เช่น `http://central-data-hub:8000` เพื่อไม่ให้ URL เปลี่ยนเมื่อเปิดเครื่องใหม่

หาก Windows Firewall ถาม ให้อนุญาต Docker/พอร์ต 8000 เฉพาะ **Private network** หรือให้ฝ่าย IT เปิด inbound rule เฉพาะเครือข่ายภายใน ห้ามเปิดพอร์ต 8000 สู่ Internet โดยตรง

## การใช้งานประจำวัน

- เจ้าหน้าที่: เปิด URL, ค้นหา, ดูรายละเอียด และ Dashboard
- ผู้ดูแล: เปิดหน้า `จัดการข้อมูล`, เข้าสู่ระบบ, ตั้งค่าแหล่งข้อมูลหรือกด Sync
- ระบบอัตโนมัติ: จะทำงานตามรอบที่ตั้งไว้ เฉพาะเมื่อ `GOOGLE_SHEETS_AUTO_SYNC_ENABLED=true` และคอมพิวเตอร์กลางกำลังเปิดอยู่

## การดูแลเบื้องต้น

- หากเข้าเว็บไม่ได้: ตรวจว่าเครื่องกลางเปิด, ผู้ดูแลลงชื่อเข้าใช้แล้ว และ Docker Desktop ทำงาน
- ดูบันทึกเริ่มระบบ: `data\logs\central-data-hub-startup.log`
- ดู container: เปิด Docker Desktop แล้วตรวจว่า `web` และ `db` เป็น Running
- ก่อนอัปเดตโค้ด: สำรอง PostgreSQL volume และโฟลเดอร์ `data` ก่อนเสมอ

## การยกเลิกการเปิดอัตโนมัติ

ผู้ดูแลสามารถรัน:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Remove-CentralDataHubAutoStart.ps1
```

คำสั่งนี้ลบเฉพาะ Scheduled Task ชื่อ `CentralDataHubStart` ไม่ลบข้อมูลหรือ container
